참가자·투표·출석·공개가 이 회차로 묶여요.

1 테이블 준비

투표용 에어테이블 3개(투표참가자·투표·투표설정)를 자동으로 만들어요. 이미 있으면 건너뛰어요. 딱 한 번만 누르면 돼요.

2 참가자 등록

🚀 로테이션 승인자 자동 불러오기 — 손으로 복붙할 필요 없어요! 위 회차의 승인된 신청자를 자동으로 참가자에 등록해요. (이미 등록된 사람은 건너뜀)
또는 직접 입력 — 한 줄에 한 명씩. 순서: 닉네임, 성별, 년생, 한줄소개, 전화번호, 음료 (쉼표로 구분)

🥤 음료 집계

등록된 음료를 자동 집계해요 — 이대로 주문하시면 돼요!

💘 성사된 커플

서로 뽑은(양쪽이 서로 찍은) 쌍이에요. 투표가 들어오면 자동으로 채워져요.

📋 투표 현황표

구글시트처럼 누가 누굴 찍었는지·성사됐는지 한눈에. (표를 ← → 옆으로 밀어보세요)
