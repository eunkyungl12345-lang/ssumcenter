1:1·로테이션·라인업·출석부 대규모 개선 + 슬랙 자동화
💘 1:1 매칭 관리자
  • 정렬 버그 수정수정
    신청일시가 한글 날짜라 최신순이 뒤죽박죽이던 문제 해결
  • 2단 정렬신규
    기준(기본/나이/키/등록일/이름) + 오름·내림차순 방향
  • 선택한 사람 상단 고정신규
    스크롤해도 사진·프로필이 위에 계속 붙어있음
  • 자유 문구 문자 보내기 칸신규
    정해진 문구 말고 직접 쓴 내용을 그대로 발송
  • 상세보기 / 작게보기 전환신규
  • 여러 명 선택 → 명단 복사(공유)신규
  • 카드 정보 정돈개선
    나이/키를 크게, 지역·직업을 한 줄로 — 한눈에 보이게
🎡 로테이션 관리자
  • 신청자 삭제 버튼신규
    확인 후 삭제
  • 문토 신청자 수기 추가신규
    유입경로 '문토' 표시 · 입금확정 상태로 등록
  • 상태별 필터신규
    전체 / 대기 / 승인 / 입금전 / 입금완료 / 거절
  • 남 / 여 2단 분리개선
🎬 라인업
  • 문토/현장 수기 추가신규
    음료 선택 포함 → 음료 집계에 자동 반영
  • 회차 선택 탭신규
    한 페이지로 과거·현재 회차 모두 관리 (새 페이지 안 만들어도 됨)
📋 출석부
  • 현장 참가자 수기 추가신규
    음료 선택 포함
  • 회차 선택 탭신규
  • 남 / 여 2단 분리 + 본명·닉네임·음료 표시개선
💬 슬랙 자동 알림
  • 승인·입금확정·수기추가 알림신규
    로테이션에서 처리하면 슬랙으로 바로 알림
  • 매일 아침 9시 요약신규
    신청/대기/입금 현황을 슬랙으로 자동 발송
🔗 자동 연동
  • 문토(선결제) → 라인업·출석부 자동 반영개선
    한 곳에서 추가하면 라인업·출석부에 자동으로 뜸
