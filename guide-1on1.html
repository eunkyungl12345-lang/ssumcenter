💘 1:1 매칭 프로세스

1:1 매칭 운영 흐름 · 센터장 전용
🏠 관리자 홈 · 💑 1:1 매칭 관리 · 📊 대시보드

🔄 전체 흐름 (신청 → 연락처 전달)

1
신청 접수 고객
고객이 1:1 신청폼에서 신청 → "1:1 매칭 신청" 명단에 등록되고, 접수 안내 문자가 자동으로 나가요.
2
프로필 검토 · 승인 센터장
1:1 관리에서 프로필·재직증명서 확인 → ✅ 승인. 부적합하면 🚫제외 / ❌거절.
3
상대 매칭 센터장
승인된 남·여 중 어울리는 두 사람 선택 → "💘 두 사람 매칭 만들기" → 양쪽에게 상대 프로필 링크 문자가 발송돼요. (상태: 소개중)
4
양쪽 응답 고객
각자 받은 링크에서 상대 프로필을 보고 수락 / 거절. 한쪽이라도 거절하면 다시 매칭 가능한 상태로 돌아가요.
5
성사 → 입금 안내 자동
둘 다 수락하면 매칭비 입금 안내 문자가 자동으로 발송돼요.
6
연락처 전달 센터장
입금 확인 후 서로의 연락처를 전달 → 매칭 완료! 💛

🏷️ 상태 뜻

대기 — 승인 전 승인 — 매칭 가능 소개중 — 응답 대기 거절 제외 — 숨김(복원 가능) 휴지통 — 삭제(복원 가능)

✅ 매칭 꿀팁

커피 궁합 — 카드 펼치면 연애테스트 기반 '잘 맞는 이성'이 자동으로 떠요. 참고해서 매칭!
선택 상단 고정 — 한 명 고르면 위에 사진·프로필이 고정돼요. 스크롤하며 짝을 편하게 찾기
2단 정렬 — 기본/나이/키/등록일 + 오름·내림차순으로 원하는 순서대로
상세/작게 보기 — 사진 크게 보거나 촘촘하게 보기 전환
직접 문자 — 카드에서 접수 안내 문자, 또는 자유 문구로 바로 발송
