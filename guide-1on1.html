3

센터장

응답 기다리기
손님
양쪽이 링크 열어서 수락/거절. 응답이 오면 슬랙에 💌수락/🙅거절 알림. 한쪽이 거절하면 불발(자동으로 다시 매칭 가능 상태로).

자동
둘 다 수락하면 매칭비 입금 안내 문자가 자동 발송. 두 분은 결제 화면을 봐요.
📍 1:1 대시보드 → '성사' 타일
6
입금 확인 → 연락처 전달
센터장
입금 확인되면 서로의 연락처를 전달(카톡/문자). 두 분의 인연 시작! 💛
📍 1:1 매칭 관리 → 매칭 현황
✅ 신청 → 승인 → 매칭 → 응답 → 성사 → 연락처 전달
한 명이라도 거절하면 불발 → 다시 다른 분과 매칭
